# Issue #117 UI監査結果

## 目的

利用者が画面ごとに別の製品を使っているように感じないよう、Fuzzy全体の情報設計、用語、状態表示、配色、ブランド資産を統一する。

## 共通ルール

- 画面名は「整理状況」「資料を検索」「課題・締切」「保存・整理設定」を基準とする。
- `native-host`、`API`、`キャッシュ`などの内部用語は通常の案内文に表示しない。必要な場合だけ開発者向けログまたは技術詳細として分離する。
- 読み込み中、表示可能、空、成功、注意、失敗の状態は `PresentationState` で表現する。
- 主要色は青、補助色はミント、注意はオレンジとし、意味を色だけに依存させず文章・ラベルも併記する。
- キーボード操作時にフォーカス位置が分かる枠線を表示する。

## ブランド資産

| 用途 | 使用する資産 |
| --- | --- |
| 公式原本、Moodle画面内、Webサイト、デスクトップ画面 | `apps/extension/public/icon/fuzzy.svg` |
| 拡張機能manifest、ブラウザ通知 | `apps/extension/public/icon/{16,32,48,96,128}.png` |

SVGを公式原本とし、PNGはブラウザAPIが必要とする用途に限る。Moodle DOMへ挿入するSVGは `web_accessible_resources` で公開し、通知用PNGは拡張機能内部から参照する。

| 範囲 | #117での対応 | 補足 |

| 整理状況 | 資料整理を主目的に変更し、「課題・締切」への短い導線を追加 | 完了 |

## 用語の対応

| 内部名 | 利用者向け表示 |
| --- | --- |
| dashboard | 整理状況／資料の整理状況 |
| deadline hub | 課題・締切 |
| native data | このPCのデータ |
| mock | サンプルデータ |
| cache | 前回保存した情報 |
| sync result: 0 changes | 最新です |

内部のAPI名や型名は互換性のため維持し、画面表示だけを分かりやすい用語へ統一する。
