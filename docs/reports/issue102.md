# Issue #102 実装報告

## 結論

括弧・角括弧を含む長いコース表示と保存先名の最適化は、PR #99で追加された共有Rustエンジンのコース保存名解決を正本とし、Issue #103の保存パネルUIから利用できるようにした。

## 対応内容

- 拡張機能はMoodleの生コース名、安定コースID、年度、学期を別フィールドで送信する
- backendが返す`courseFolder.folderName`、`name_conflict`、`name_shortened`を保存パネルへ表示する
- 利用者が保存前に別名を編集し、SQLiteへ保存できる
- 拡張機能側には括弧除去・短縮・衝突回避のTypeScript実装を追加していない

## 仕様との関係

正規化対象は`docs/仕様書.md` 1.1節と`docs/api/contract.md` 1.2節に従う。未知・曖昧な括弧内容を一律削除せず、年度・学期・明示的な担当者表記等だけをbackendが除去する。
