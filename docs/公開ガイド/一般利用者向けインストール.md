# 一般利用者向けインストール

## 対応環境

- Windows 11
- Google ChromeまたはMicrosoft Edge
- Fuzzyが対応する和歌山大学Moodle

Windowsアプリとブラウザ拡張機能の両方が必要です。ブラウザ拡張機能だけでは、資料保存、SQLite、検索などを利用できません。

## 正式版のインストール

1. Fuzzy公式公開ページを開く
2. Windows版の`Fuzzy-Setup.exe`をダウンロードする
3. ダウンロードしたファイルの発行元と署名を確認する
4. `Fuzzy-Setup.exe`をダブルクリックする
5. インストーラーの案内に従って、現在のWindowsユーザーへインストールする
6. Fuzzyを起動する
7. 資料を保存するフォルダーを選ぶ
8. 既存資料の確認結果と初期ルールを画面で確認する
9. Fuzzy画面の「ブラウザ拡張機能を追加」を押す
10. Chrome Web StoreまたはMicrosoft Edge Add-onsで、表示された権限を確認して追加する
11. 対応Moodleを開く
12. Fuzzy画面が拡張機能からの実応答を確認し、完了表示になるまで待つ

ターミナル、PowerShell、レジストリエディター、ZIP展開、native-hostの手動登録は不要です。拡張機能の追加だけはブラウザの権限確認が必要なため、利用者自身が行います。

## 公開審査前のQA版

QA担当者は、[Fuzzy v0.1.0-qa.3 Pre-release](https://github.com/Fuzzy-app/fuzzy/releases/tag/v0.1.0-qa.3)の`Fuzzy-Setup.exe`を使用します。QA版は未署名であり、正式な一般公開版として配布しません。ダウンロード元、警告時の判断、不具合報告は[QAプレリリースの試し方](QAプレリリース.md)を参照してください。

1. `Fuzzy-Setup.exe`をインストールする
2. Fuzzyで保存先とルールを設定する
3. 「同梱フォルダーを表示」を押す
4. Chromeは`chrome://extensions`、Edgeは`edge://extensions`を開く
5. デベロッパーモードを有効にする
6. 「パッケージ化されていない拡張機能を読み込む」を押す
7. Fuzzyが表示した`chrome-mv3`フォルダーを選ぶ
8. Moodleを開き、Fuzzyの完了表示を確認する

この手順にもコマンドは不要ですが、正式版ではデベロッパーモードを使用しません。

## データ保存

SQLite正本は通常、次へ保存します。

```text
%LOCALAPPDATA%\Fuzzy\fuzzy.db
```

資料本体は、利用者がセットアップ画面で選択したフォルダーへ保存します。Fuzzyは保存済み資料を自動で移動・削除しません。

ブラウザのIndexedDBはダッシュボード表示用キャッシュであり、SQLiteの代わりではありません。

## 日常利用

1. Moodleへ通常どおりログインする
2. 対応コースまたはダッシュボードを開く
3. Moodle上のFuzzy UIから資料、課題、締切、検索、ルール画面を利用する
4. 資料保存では、候補、類似ファイル、保存先を確認してから利用者が実行する
5. 通知はFuzzyの通知設定を有効にした場合だけ表示する

## 保守と復旧

Fuzzyデスクトップ画面から次を行えます。

- Native Messaging接続の自動修復
- 保存先の変更
- 保存先の再スキャン
- 検索索引の再構築
- SQLiteバックアップの書き出し
- バックアップからの復元
- 開けないSQLiteを別名保全した後の新規開始
- SQLiteを正本とした検索索引の再生成

保守処理中は資料保存が完了していることを確認し、ブラウザを閉じます。これらの操作で授業資料を自動移動・削除しません。

## 別PCへの移行

1. 旧PCのFuzzy画面からバックアップを書き出す
2. 利用者自身の方法で資料フォルダーとバックアップを新PCへコピーする
3. 新PCへFuzzyをインストールする
4. Fuzzyの復元画面からバックアップを選ぶ
5. 「保存先を変更」で新PCの資料フォルダーを指定する
6. SQLite上の登録先と検索索引を再構築する

Fuzzyは資料フォルダー自体をクラウドや新PCへ転送しません。

## アンインストール

1. 資料保存が完了していることを確認する
2. Chrome／Edgeを閉じる
3. Windowsの`設定 → アプリ → インストールされているアプリ`を開く
4. Fuzzyを選び、アンインストールする
5. ブラウザの拡張機能管理画面からFuzzyを削除する

アンインストーラーはNative Messaging登録とmanifestを削除しますが、誤削除を防ぐため、資料、SQLite、検索索引、バックアップを削除しません。

## Fuzzyデータをすべて削除する場合

1. Fuzzyとブラウザを終了する
2. 保存した資料を残すか削除するか利用者自身で判断する
3. エクスプローラーで`%LOCALAPPDATA%\Fuzzy`を開く
4. SQLite、索引、復旧用フォルダー、バックアップの内容を確認する
5. 不要なものだけをWindowsの通常操作で削除する

資料フォルダーは別の場所にあるため、`%LOCALAPPDATA%\Fuzzy`だけを削除しても授業資料は削除されません。

## 困ったとき

| 状態 | 対処 |
|---|---|
| 拡張機能と接続できない | Fuzzyを起動し「Native Messaging接続を自動修復」を押し、ブラウザとMoodleを開き直す |
| 応答が古い | Fuzzyの「Moodleを開いて再確認」からMoodleを開く |
| 拡張機能が非互換 | 公式ストアで最新版へ更新または再インストールする |
| 資料が検索に出ない | 資料保存の完了を確認してブラウザを閉じ、保存先の再スキャン・索引再構築を行う |
| SQLiteを開けない | 起動時の復旧画面からバックアップを復元する |
| バックアップがない | 復旧画面の説明を確認し、DBを別名保全して新しく開始する |
| 索引だけを開けない | SQLiteから検索索引を再構築する |
