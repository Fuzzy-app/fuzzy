# desktop

Fuzzyの初期セットアップを行うTauri 2 + SvelteKitアプリ。

保存先・保存パターン・初期ルールを設定した後、Fuzzyブラウザ拡張機能の導入を必須で案内する。ブラウザ名による分岐や自己申告チェックは行わず、拡張機能からnative-hostへ届いてSQLiteに保存された実応答を確認すると完了する。

初期設定の保存時に既存資料をSQLiteと全文検索索引へ登録し、セットアップ後の画面では保存先の再スキャン・索引再構築とSQLiteバックアップの書き出し・復元を提供する。すべて画面上の明示操作とOSダイアログで行い、資料ファイルの移動・削除や既存バックアップの上書きはしない。

SQLite正本を開けない場合もアプリをpanicさせず、起動時のGUIからバックアップ復元、または確認付きで破損DBを別名保全した後の新規作成を行える。検索索引だけを開けない場合は、SQLiteを正本として派生索引を再生成する。復旧後は同じAppStateで通常画面へ戻り、利用者にコマンド操作を要求しない。

開発・レビュー段階では拡張機能とnative-hostをTauriへ同梱する。NSISインストーラーはnative-hostのユーザー単位登録とアンインストール時の解除を自動で行い、一般利用者にコマンド操作を要求しない。拡張機能の追加だけはブラウザ上の明示操作を必須とし、サイレントインストールしない。

Windowsテスト配布はルートの`bun run dist:windows`で作成し、`dist/Fuzzy-<version>-windows/`直下へ一般向けインストーラー・SHA-256一覧・READMEを、`QA-確認用/`へポータブル版・native-host・拡張機能ZIPを分離して集約する。一般公開前には外部のコード署名証明書を設定する。

開発時の起動方法とNative Messagingホストの前提は`docs/セットアップ.md`を参照する。
