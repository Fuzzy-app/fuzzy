正式公開後の導入手順

4つの段階で、
Moodleから使い始める。

正式公開後はWindowsアプリをインストールし、ブラウザ拡張機能は公式ストアから追加します。ターミナルやデベロッパーモードは使用しません。

ダウンロードへ戻る ↑
  1. 1

    Windowsアプリ

    インストールして初期設定

    Windows 11用の.exeを実行し、Fuzzyの画面で資料の保存先を選びます。Native Messaging Hostの登録も自動で完了します。

  2. 2

    ブラウザ拡張機能

    公式ストアを開く

    このページの案内から、利用するブラウザの公式拡張機能ストアにあるFuzzyのページを開きます。

  3. 3

    ブラウザ

    権限を確認して追加

    公式ストアに表示される提供元と必要な権限を確認し、ブラウザの追加ボタンを押します。コマンド操作は不要です。

  4. 4

    Moodle

    Fuzzyタブから利用開始

    Moodleを開き、拡張機能からFuzzyアプリへの実応答を確認します。接続が完了したら、Moodle上に表示されるFuzzyタブから機能を開きます。

よくある質問

導入前の疑問に
答えます。

今すぐダウンロードできますか？

正式版はまだダウンロードできません。QA参加者は、上記の未署名QAプレリリースからテスト版を取得できます。正式版の公開後、このページからアプリと拡張機能を直接取得できるようにします。

拡張機能は自動で追加されますか？

自動では追加しません。開発・レビュー中はTauriアプリに同梱された拡張機能を利用します。正式公開後は公式ブラウザストアで提供元と権限を確認し、利用者が追加します。

Chrome以外のブラウザでも使えますか？

Chrome限定ではありません。Manifest V3とNative Messagingに対応し、Fuzzyとの接続を確認できるブラウザが対象です。正式に確認できたブラウザはリリース時に掲載します。

保存した資料は勝手に移動されますか？

Fuzzyは保存先や整理方法を提案します。保存済みファイルの移動や削除は、利用者への提示・確認を前提とします。

不具合や要望はどこへ送ればよいですか？

GitHub Issuesから、再現手順や画面の状態を添えて報告できます。
